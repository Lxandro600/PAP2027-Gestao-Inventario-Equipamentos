## Descrição

Este projeto consiste no desenvolvimento de um website para gerir equipamentos informáticos de uma escola. Vai permitir registar equipamentos, consultar informações, alterar dados e eliminar registos. O objetivo é facilitar a organização dos equipamentos e saber onde se encontram e em que estado estão.

## Objetivos

- Facilitar a gestão dos equipamentos informáticos da escola.
- Permitir consultar a localização e o estado dos equipamentos.
- Melhorar a organização e o controlo dos equipamentos.
